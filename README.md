# Over the Wall

바람을 읽고 투척의 세기를 조절해 중앙 벽 너머의 상대를 맞히는 1:1 턴제 포격 게임입니다. 라쿤 Rocco와 다람쥐 Hazel이 뒷마당에서 통조림과 도토리를 던지며 겨룹니다.

[브라우저에서 플레이](https://legerdo.github.io/over-the-wall/)

## 게임 소개

Over the Wall은 HTML Canvas와 순수 JavaScript로 만든 작은 아케이드 게임입니다. 바람과 투척 세기를 고려해 벽 너머의 상대를 맞히고, 상대의 체력을 먼저 0으로 만들면 승리합니다.

- **1인 플레이:** 초급, 보통, 어려움 중 하나를 골라 CPU와 대결합니다.
- **2인 플레이:** 한 기기에서 두 사람이 번갈아 플레이합니다.
- **매 경기마다 달라지는 바람:** 바람의 방향과 세기가 투사체 궤적에 영향을 줍니다.
- **네 가지 특수 행동:** 더블 공격, 파워 투척, 스팅크 투척, 회복을 상황에 맞춰 사용합니다.
- **마우스, 터치, 키보드 조작:** 화면 크기에 맞춰 게임 화면이 비율을 유지하며 조정됩니다.

## 플레이 방법

1. 시작 화면에서 **1 PLAYER** 또는 **2 PLAYERS**를 선택합니다. 1인 플레이는 CPU 난이도도 선택합니다.
2. 내 차례에 현재 바람과 남은 시간을 확인합니다. 바람은 매 차례 달라질 수 있습니다.
3. 필요하면 특수 행동을 하나 선택합니다. 각 행동은 플레이어마다 한 경기에서 한 번 사용할 수 있습니다.
4. 게임 필드에서 누르고 있으면 투척 세기가 차오릅니다. 원하는 세기에서 손을 떼면 벽 너머로 던집니다. 세기 게이지가 끝까지 차면 다시 줄어들기 시작합니다.
5. 상대의 체력을 0으로 만들면 승리합니다. 한 차례 제한 시간은 10초입니다.

### 특수 행동

| 행동 | 효과 |
| --- | --- |
| **DOUBLE** | 투사체 두 개를 연속으로 던집니다. 각각 맞으면 각각 피해를 줍니다. |
| **POWER** | 한 번의 강한 투척으로 35 피해를 줍니다. |
| **STINK** | 악취 투척으로 25 피해를 줍니다. |
| **HEAL** | 체력을 최대 25 회복합니다. 회복하면 차례가 끝납니다. |

일반 투척은 20 피해를 주며, 양쪽 플레이어는 100 체력으로 시작합니다. 회복은 체력이 줄어든 경우에만 사용할 수 있습니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 또는 터치로 누르고 떼기 | 게임 필드에서 누르는 동안 세기를 충전하고, 떼면 투척합니다. 메뉴와 버튼은 눌러 선택합니다. |
| **Space** 누르고 떼기 | 키보드로 투척 세기를 충전하고 발사합니다. |
| **1**, **2**, **3**, **4** | 차례 중 DOUBLE, POWER, STINK, HEAL을 선택합니다. |
| **Esc** 또는 **P** | 경기 중 일시 정지합니다. 선택 화면에서는 이전 메뉴로 돌아갑니다. |
| **M** | 소리를 켜거나 끕니다. |
| **방향키**, **Tab**, **Enter** | 메뉴 항목을 이동하고 선택합니다. |

## 로컬에서 실행하기

### Windows

프로젝트 폴더에서 `run.bat`을 더블클릭하면 기본 브라우저로 게임이 열립니다. Node.js, npm, 설치 과정은 필요하지 않습니다.

### 다른 환경

프로젝트를 내려받거나 복제한 뒤 `index.html`을 최신 브라우저에서 엽니다. 별도의 빌드나 개발 서버 없이 실행할 수 있습니다.

```bash
git clone https://github.com/Legerdo/over-the-wall.git
cd over-the-wall
```

게임 플레이에는 JavaScript를 사용할 수 있는 최신 브라우저가 필요합니다.

## 개발 및 테스트

게임 실행 자체에는 패키지를 설치할 필요가 없습니다. 테스트를 실행할 때만 Node.js와 개발 의존성을 설치합니다.

```bash
npm ci
npm test
```

브라우저에서 실제 입력을 확인하는 플레이 테스트는 로컬 Microsoft Edge를 사용합니다.

```bash
npm run playtest
```

`npm run playtest -- --shots`를 실행하면 테스트 화면 캡처가 `shots/`에 저장됩니다. 테스트 산출물과 `node_modules/`는 Git에 포함하지 않습니다.

## 기술 구성

- **화면:** HTML, CSS, Canvas 2D
- **게임 코드:** 빌드 도구와 런타임 패키지에 의존하지 않는 JavaScript
- **투사체 물리:** 프레임률에 좌우되지 않도록 고정 간격으로 시뮬레이션
- **CPU:** 난이도에 따라 바람 판단과 조준 오차가 달라지며, 이전 투척 결과를 반영합니다.
- **접근성:** 키보드 메뉴 탐색과 스크린 리더용 상태 안내를 지원하고, 운영체제의 동작 줄이기 설정을 반영합니다.
- **테스트:** Node.js 내장 테스트 러너와 Playwright 기반 브라우저 플레이 테스트

## 기획 문서

초기 게임 규칙과 완료 기준은 프로젝트 루트의 `프롬프트` 파일에 정리되어 있습니다.

## 라이선스

현재 별도의 라이선스 파일은 포함되어 있지 않습니다.

```text

├── index.html          게임 페이지
```
